AntiNHelper v0.3.7 Beta

Данный проект создан исключительно в демонстрационных целях, а именно для показа масштаба проблемы в защите программы NHelper.
На данный момент в данном проекте уже 3 серьёзные уязвимости, подробнее можете узнать в репозитории на GitHub по кнопке ниже.

Уязвимости NHelper:

№ Название уязвимости Причина
0 Имя процесса в каталоге %Temp%\.net Использование .NET Fraemwork (возможно .NET Core)
1 Параметр EnableBlockSearch в реестре Защита для своих вирусов.
2 user.config в %localappdata%\NHelperV4 Не понимаю зачем этот файл

Другие проблемы программы NHelper

№ Проблема Возможная причина
0 Закрытый исходный код Разработчик боится своего говнокода
1 Утечка памяти при обновлении интерфейса говнокод и чрезмерное использование нейросетей
2 Долгая прогрузка интерфейса на слабых ПК Использование тяжёлого графического интерфейса
