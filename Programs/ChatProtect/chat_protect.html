Защита чата - NEO Organization

ChatProtect - это open-source бот на python для автоматической модерации чата в телеграмме с тонкой настройкой, а помимо этого бот также имеет систему "шуток" и репутаций.

Бот содержит, следующие функции:

  • Автоматическая проверка сообщений на запрещённые слова
  • Система исключений
  • Система модераторов
  • Базовый набор команд
  • Система "шуток"
  • Система репутаций
  • Капча для новых пользователей
  • Резервное копирование базы данных

Особенности:

  • Открытый исходный код под AGPL
  • Поддержка работы на ОС Android
  • Система репутаций
  • Система "шуток"
  • Система приветствий
  • Гибкая настройка
