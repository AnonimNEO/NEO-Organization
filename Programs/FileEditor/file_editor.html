Текстовый Редактор - NEO Organization

Текстовый Редактор - это лёгкий, простой и open-source блокнот на python. Также данный блокнот поддерживает поиск и шифрование. Код распространяется под лицензией GPLv3.

Функционал Редактора Файлов:

  • Редактирование текстовых файлов (удивительно)
  • Изменение шрифта и его размера
  • Поиск с подсветкой совпадений
  • Работой поверх остальных окон
  • Система тем(временно не работает)
  • Возможность шифрования содержимого файлы через AES шифрование
  • Система локализации на разные языки
